# Kalasetu Animated Logo

Files:
- index.html
- style.css
- script.js
- assets/kalasetu-layered.svg

## Run it

1. Keep the folder structure unchanged.
2. Open index.html in a browser.
3. The intro animation runs for about 4.8 seconds.
4. Click Skip to bypass it.

## Put it into your existing website

Copy:
- assets/kalasetu-layered.svg
- the relevant intro HTML
- the CSS
- the JS

into your existing project.

## Animation sequence

0.1s  Bridge
0.8s  Pot
1.5s  Road
2.2s  Leaves
2.9s  Kalasetu
4.2s  Intro begins fading
4.8s  Website is visible

The SVG is layered using these IDs:
#bridge
#pot
#road
#leaves
#wordmark

That means you can independently change the timing or animation of any part.
